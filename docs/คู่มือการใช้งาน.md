# คู่มือการใช้งาน — แอปคะนึงถึง

เปิดแอป: https://kanuengthueng.juybakerry.workers.dev (ติดตั้งลงหน้าจอได้ ดูหัวข้อสุดท้าย)

## เมนูหลัก

มือถือใช้เมนูล่าง 5 ปุ่ม: **วันนี้ · ปฏิทิน · การจอง · สรุปผล · เพิ่มเติม** และปุ่มส้ม **+ จองใหม่** มุมขวาล่าง
แท็บเล็ต/คอมพิวเตอร์ใช้เมนูด้านซ้าย

ป้ายมุมบน **"บันทึกแล้ว"** = ข้อมูลขึ้นเซิร์ฟเวอร์แล้ว · **"รอซิงก์ 2"** = มี 2 รายการรอส่ง (เน็ตหลุด) ใช้งานต่อได้ตามปกติ ระบบจะส่งเองเมื่อสัญญาณกลับมา

## รับจองใหม่ (3 แตะ)

1. แตะ **+ จองใหม่**
2. **วันที่:** แตะวันเข้าพัก แล้วแตะวันออก (ตัวเลขใต้วัน = ที่ว่างจาก 24)
3. **ห้อง/คน:** ใส่จำนวนผู้ใหญ่/เด็ก แล้วแตะห้อง ระบบจัดคนลงห้องตามลำดับที่แตะ ถ้าเกินจะขึ้นแถบแดงบอกว่ารับได้อีกกี่คน · ติ๊ก "จองทั้งห้อง" ถ้าไม่ให้กลุ่มอื่นพักร่วม · เปิด "ใช้รถรับส่ง" แล้วใส่จุดรับและเวลา
4. **ลูกค้า:** พิมพ์ชื่อหรือเบอร์ในช่องค้นหาเพื่อเลือกลูกค้าเก่า หรือกรอกใหม่ (ชื่อ เบอร์ จำเป็น)
5. **ชำระเงิน:** เลือก ยังไม่ชำระ / มัดจำ 50% / ชำระเต็ม · ช่องทาง · แนบสลิป แล้วแตะ **บันทึกการจอง**

## หน้ารายละเอียดการจอง

- ปุ่มด่วน: **โทร · LINE** (ส่งข้อความสรุปยอด) **· ส่ง QR** (QR พร้อมเพย์พร้อมยอด) **· ใบยืนยัน**
- **รับมัดจำ / รับส่วนที่เหลือ:** ใส่ยอด เลือกช่องทาง แนบสลิป · ลบรายการที่บันทึกผิดได้ (มีประวัติเก็บไว้)
- ปุ่มล่าง: **เช็คอิน → เช็คเอาท์ → ส่งแบบประเมิน**
- **แก้ไข** (ห้อง จำนวนคน ข้อมูลลูกค้า ส่วนลด) · **เลื่อนวัน** (นับครั้งตามนโยบาย) · **ยกเลิกการจอง** (มัดจำไม่คืน) · **ไม่มาเข้าพัก**
- **ประวัติการแก้ไข** ด้านล่าง: ใครทำอะไร เมื่อไร จากเครื่องไหน

## ใบยืนยัน / ใบเสร็จ

แตะ **ใบยืนยัน** › เลือกแท็บใบยืนยันหรือใบเสร็จ › **ส่งทาง LINE** (เลือก LINE ในเมนูแชร์ แล้วเลือกแชทลูกค้า) หรือ **บันทึก PDF**

## ปฏิทิน

**รายเดือน** (ปัดซ้าย-ขวาเปลี่ยนเดือน แตะวันดูรายละเอียดและ "จองวันนี้") · **รายสัปดาห์** · **ห้อง × วัน** (แตะช่องว่างเพื่อจอง แตะช่องสีเพื่อเปิดการจอง)
สี: แดง = ยังไม่ชำระ · เหลือง = มัดจำแล้ว · เขียว = ชำระครบ · ฟ้าเทา = กำลังพัก · ลายเส้นทแยง = ปิด

## แจ้งปัญหา / ค่าใช้จ่าย

เพิ่มเติม › แจ้งปัญหา › ถ่ายรูป › หัวข้อ › จำนวนเงิน › หมวด › ห้อง › สถานะ · ถ้าลูกค้าทำเสียหาย เปิด **เรียกเก็บคืนจากลูกค้า** (นับเป็นรายรับ) · แตะป้ายสถานะในรายการเพื่อเปลี่ยน รอแก้ไข → กำลังแก้ → เสร็จแล้ว

## สรุปผล

เลือก วันนี้ / เดือนนี้ / ปีนี้ / เลือกช่วงวัน · ดูรายรับ กำไรสุทธิ ยอดค้าง อัตราเข้าพัก (เทียบช่วงก่อน) · ต้นทุนแยกประเภท · **Excel / PDF** ส่งออกรายงาน
รายรับนับตามคืนที่เข้าพัก · ค่าใช้จ่ายจากปัญหานับตามวันที่จ่าย · ต้นทุนคงที่เฉลี่ยรายวัน

## คำขอจองออนไลน์

ลูกค้าส่งคำขอจากหน้า `/book` → แอปแจ้งเตือน → เพิ่มเติม › คำขอจองออนไลน์ › **รับจอง** (เปิดฟอร์มจองที่กรอกไว้ให้) หรือ **ปฏิเสธ** · โทรหรือทัก LINE ลูกค้าเพื่อแจ้งยอดมัดจำ

## ปิดห้อง / ปิดวัน

ตั้งค่า › ปิดห้อง / ปิดวัน › เลือกห้องหรือทั้งโฮมสเตย์ ช่วงวัน และเหตุผล (ช่วงที่มีคนจองอยู่จะปิดไม่ได้ ต้องย้ายแขกก่อน)

## สองเครื่อง และข้อมูลชนกัน

แก้ที่เครื่องหนึ่ง อีกเครื่องเห็นภายในไม่กี่วินาที ถ้าทั้งสองเครื่องแก้รายการเดียวกันตอนเน็ตหลุด จะมีกล่อง **ข้อมูลชนกัน** ให้เลือกว่าเก็บของเครื่องไหน

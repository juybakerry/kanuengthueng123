## ติดตั้งบนมือถือ

- **iPhone / iPad:** เปิดลิงก์ด้วย Safari › ปุ่มแชร์ › "เพิ่มไปยังหน้าจอโฮม" › เปิดจากไอคอน "คะนึงถึง" แล้วเข้าสู่ระบบ › ตั้งค่า › การแจ้งเตือน › เปิดการแจ้งเตือน (ต้อง iOS 16.4+)
- **Android:** เปิดด้วย Chrome › เมนู ⋮ › "ติดตั้งแอป" (หรือเมนู เพิ่มเติม › ติดตั้งแอปลงหน้าจอ ในแอป)
- แอปมีหน้าแนะนำการติดตั้งในตัว: เพิ่มเติม › ติดตั้งแอปลงหน้าจอ

## เริ่มใช้งานจริง (สิ่งที่เจ้าของทำเอง)

1. เข้าสู่ระบบด้วยบัญชีใน `.secrets/บัญชีผู้ใช้.txt` แล้วเปลี่ยนรหัสผ่านทั้งสองบัญชี
2. ตั้งค่า › การรับเงิน: ใส่เลขพร้อมเพย์และชื่อบัญชี แล้วสแกน QR ทดสอบ ฿1 ด้วยแอปธนาคารเพื่อตรวจชื่อ
3. ตั้งค่า › ต้นทุนคงที่รายเดือน: ใส่ค่าไฟ ค่าน้ำ ค่าอินเทอร์เน็ต
4. ตั้งค่า › ห้องพัก: แก้ชื่อห้องที่ใช้จริง (ถ้ามี) · ข้อมูลกิจการ: เบอร์โทร LINE ID ของร้าน
5. ติดตั้งแอปบนทั้ง 2 เครื่อง และเปิดการแจ้งเตือนในแต่ละเครื่อง
6. (ไม่บังคับ) ราคาพิเศษช่วงเทศกาล · ส่งลิงก์ `/book` ลงเพจ Facebook

## ดูแลระบบ

คำสั่งทั้งหมดรันในโฟลเดอร์นี้ (บนเครื่องนี้ต้องใส่ `COMSPEC='C:\Windows\system32\cmd.exe'` หน้าคำสั่งใน Git Bash)

```bash
npm install
npm run typecheck && npm test        # ตรวจชนิดข้อมูล + unit test
npm run worker:dev                   # เซิร์ฟเวอร์ local พอร์ต 8797 (ใช้ dist/ ที่ build แล้ว)
npm run dev                          # หน้าแอปแบบแก้แล้วเห็นทันที พอร์ต 5174 (ส่ง /api ไปที่ 8797)
node scripts/e2e-api.mjs             # ทดสอบ API ทั้งวงจร 34 ข้อกับเซิร์ฟเวอร์ local
npm run deploy                       # build + อัปขึ้น Cloudflare
npm run db:migrate:remote            # เมื่อมีไฟล์ใหม่ใน migrations/
node scripts/backup.mjs              # สำรองฐานข้อมูลจริงลง backups/ บนเครื่องนี้
```

- **ค่าลับ** (`.secrets/PROD-KEYS.txt`): `ADMIN_TOKEN`, คีย์ VAPID — ตั้งบนเซิร์ฟเวอร์ด้วย `wrangler secret put <ชื่อ>`
- **ลืมรหัสเจ้าของ:** `node scripts/create-user.mjs https://kanuengthueng.juybakerry.workers.dev <ADMIN_TOKEN> owner2 "เจ้าของกิจการ" owner` แล้วใช้บัญชีใหม่ตั้งรหัสให้บัญชีเดิม
- **ดู error จากเครื่องผู้ใช้:** `GET /api/admin/errors` พร้อม `Authorization: Bearer <ADMIN_TOKEN>`
- **กู้คืน:** ในแอป ตั้งค่า › ข้อมูล › กู้คืนจากไฟล์ (ไฟล์ JSON จากปุ่มดาวน์โหลดหรือไฟล์สำรองรายวัน) — ระบบสำรองข้อมูลปัจจุบันไว้ก่อนเสมอ · หรือ `wrangler d1 time-travel restore kanuengthueng --timestamp <เวลา>` (ย้อนได้ 7 วัน)

### LINE Official Account (ไม่บังคับ)

ใช้ส่งสรุปแขกพรุ่งนี้ทุกเย็นเข้าแชทพนักงาน (ฟรี 300 ข้อความ/เดือน ใช้ราว 30–60) — การส่งเอกสารให้ลูกค้าใช้ปุ่มแชร์ของมือถือ ไม่ใช้โควต้า

เชื่อมแล้วกับ OA **คะนึงถึงโฮมสเตย์ (@691oyluh)** (21 พ.ย. 2569) ถ้าต้องเปลี่ยนคีย์ใหม่:

1. ใส่ Channel secret บรรทัดแรก และ Channel access token บรรทัดที่สอง ใน `.secrets/line.txt`
2. `node scripts/connect-line.mjs` — ตั้งคีย์บนเซิร์ฟเวอร์ ตั้ง Webhook URL และทดสอบให้
3. ในแอป: ตั้งค่า › การแจ้งเตือน › ขอรหัสลงทะเบียนแชท แล้วพิมพ์ `ลงทะเบียน <รหัส>` ในแชท OA · พิมพ์ `พรุ่งนี้` เพื่อดูสรุปได้ทุกเมื่อ

### Cloudflare Turnstile สำหรับหน้าจอง (ไม่บังคับ)

ตอนนี้หน้าจองกันสแปมด้วยการจำกัด 5 คำขอ/ชั่วโมง/เครื่อง + ช่องดักบอท ถ้าต้องการเพิ่ม Turnstile (ฟรี): สร้าง widget ใน Cloudflare Dashboard › Turnstile แล้วใส่ `TURNSTILE_SITE_KEY` ใน `wrangler.toml` และ `npx wrangler secret put TURNSTILE_SECRET` แล้ว deploy
